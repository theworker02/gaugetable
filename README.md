# gaugetable

Gauge structured JSON table payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/gaugetable/

## Install / run

```bash
git clone https://github.com/theworker02/gaugetable.git
cd gaugetable
node src/cli.js
node --test
```
